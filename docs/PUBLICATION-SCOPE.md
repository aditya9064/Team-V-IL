# Publication scope —25 October2026

This update publishes the current assembly source families, larger-part CAD, tests, camera diagnostic, IndustReal integration and public requirements analysis. It retains the existing kitting/dataset/training code.

Credentials, private conversations/approval receipts, datasets, model weights, raw supplied simulator/CAD assets, generated videos, large runtime archives and thousands of duplicate intermediate snapshots remain outside Git. Historical experiments remain available in the local/remote experiment archive. Publication never converts a CPU check, job exit or nominal motion completion into an accepted assembly or real-hardware result.

The larger-part publication removes a private approval reference from design metadata and updates its corresponding file identities; geometry, mass properties and numerical gates are unchanged. The original sealed candidate is retained separately. Published source has not been used for a new GPU experiment.
