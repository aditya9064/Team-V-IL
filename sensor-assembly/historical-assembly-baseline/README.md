# Historical full-motion assembly baseline

This source family records the original-size known-fixture assembly experiments. Run287941 completed the three-part motion sequence. Its independent final support-force certificate was inconclusive; this is not an accepted full assembly or physical/print qualification. Later offset variations failed contact checks.

It is preserved for reproducibility and diagnosis, not as the default prototype. The current larger-part work is in ../option-a. Supplied FANUC/SMC SDK assets, datasets, weights, videos, private approvals and connection details are excluded. Several regression fixtures and source-migration tests refer to the original internal source snapshots; recover those from the experiment archive before using those historical checks.
