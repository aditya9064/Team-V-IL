# Varied dataset pilot — October 14, 2026

The v2 generator preserves the starter files, 10mm upright cube geometry and physics. It runs one Isaac application with fresh stages and fixed 90-frame warmup per capture. Dataset capture deliberately varies the starter inventory; this is not an executable six-cube stacking plan.

Pilot profiles contain0,1,3,6,8,6cubes. All colours, including yellow, move within the original conservative workspace. Cube yaw, cap/vial positions, vial yaw, lighting, neutral paper shade/roughness and mild table-camera pose/intrinsics vary reproducibly by seed. Saved calibration is read from each actual USD camera. Camera perturbations are synthetic augmentation, not a replacement for CSI calibration. Cube reachability/physical grasps for these new scenes are unverified.

## Important label correction

The starter SortCube root is at the bottom-face centre (`cell.py` translate at surface; collider translated upward by edge/2). The older exporter incorrectly placed eight vertices symmetrically around that root. Existing `synthetic-v1` and its crops must not be used for training until labels are rebuilt. Colours/inventory were not the issue; projected box heights were wrong. Local `export_dataset.py` now uses local z=0..edge. Remote corrected legacy exporter is a separate `export_dataset_originfix.py`; the old export is preserved.

`varied_labels.py` reads actual saved USD origins/quaternions and camera calibration, projects the correctly placed eight vertices, rasterizes at pixel centres and compares the predicted silhouette with the matching rendered colour component. Requires IoU>=.85, matching count/identity/colour/XY/yaw, upright cubes on the surface, in-frame hulls, and no overlapping cube boxes. YOLO labels use the visible component's exclusive pixel bounds. This initial method rejects occlusions; it is not an occlusion-capable exporter. Empty scenes have empty labels. GT is used for synthetic label generation/evaluation only, never robot targeting.

The known ten-scene pilot's60cubes passed this image-based check (minimum silhouette IoU .922). Negative probes rejected altered colours/positions; a projection fixture verifies bottom-origin geometry. Near-zero float quaternion angles are numerically quantized by USD; geometry uses the actual saved quaternion and authored yaw agrees within .05deg. Existing robot confidence/grasp gates are unchanged.

Labels use YOLO text format: class0 yellow,1 blue,2 red, followed by normalized box centre/width/height. The planned Faster R-CNN training adapter must map these to foreground labels1,2,3 because0 is its background class. Keep empty scenes and supply empty target arrays. Do not silently discard them or pass YOLO class0 as Faster R-CNN background. Training packaging and adapter validation remain a separate next step.
